Room host

One word puts your room at the top of a domain's front page as a Join the swarm button. Anyone who opens the page can join, and never sees the room's name or secret.

In one minute

Join the room you want to show. Then, inside it, say:

room host example.com @hypercomb.com

The room is sealed, signed into the domain's front-page card, and drawn above the domain's name. The word then opens the page again and tells you whether the button is really there. To take it down, say room host off example.com.

Step by step

  1. 01Join the room. The word shows the room you are in, so be inside it first. Without a room it asks you to join one.
  2. 02Say the word. room host <domain> @<host>. The domain is the front page that shows the button. The host is where your signed card is kept; hypercomb.com is the one that holds your published pages. Set it once as your public host in hosts and you can leave it off.
  3. 03Read what it says. It opens the page again, and once more a few seconds later, and tells you one of three things: the button is there, the button is not there and why, or the page could not be reached to check.
  4. 04Change it. Saying the word again from another room replaces the room on the card. The card's title and tagline are kept as they were.
  5. 05Take it down. room host off <domain> signs the card without the room.

If you are the visitor

  1. 01Open the page. The button reads Join the swarm and sits above the domain's name.
  2. 02Tap it. You land on the swarm door, and it asks before it puts you in the room.
  3. 03Say yes. You are in the room, with everyone else who is.

What it hides, and what it does not

The link carries a key, not the words. It hides the room's name, its secret, its access code and the page it opens on, from the address bar and from the page's text.

It does not keep them from anyone who joins. The room is public, only hidden.

It does not hide where the room meets. The meeting host is named in the link, because a browser has to know where to fetch the sealed login.

A room on a meeting point that needs an access code hands that code out too, and the code opens the whole meeting point, not just this room. To close such a room, change the code as well as the secret.

Taking it down for good

room host off takes the button off the page. Earlier versions of the card are never deleted, so an old copy still holds the old link. To close the room for good, change its secret.

When the page does not show it

A signed card reaches only a front page that the Hypercomb host serves, and only in the order of the domain's publishers. If the button is missing, the word says which of these it is:

  1. 01The domain is its own site. A domain that is served somewhere else does not read signed cards. The word also looks at host.<domain>, where a domain that opens on a page of its own keeps its card.
  2. 02Someone is ahead of you. The first publisher of a domain who signs a card decides whether the page shows a room. A card with no room shows none, so no one behind them can put one there.
  3. 03The page could not be reached. Then the word says so, and does not guess.

Every word

Room host
room host <domain>
Put the room you are in on that domain's front page.
room host <domain> @<host>
The same, keeping the card on that host.
room host off <domain>
Take the room off the front page.

invite
