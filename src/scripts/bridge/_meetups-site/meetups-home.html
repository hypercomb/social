    What makes it different

    Nine promises we make to everyone who joins.

    01No email or personal information

    You never give us an email, phone number or name. Your phone or computer creates a private key that stands in for you.

    02Security by community

    Instead of a company checking your identity, the people already in the group vouch for newcomers — the way a real community does.

    03Domain agnostic

    The meetup can be reached from any website address. If one goes away, the group carries on at another.

    04Platform agnostic

    Works the same on phone, tablet and computer, in any web browser. Nothing to download.

    05Pure edge computing

    Everything happens on your own device. There is no central server that stores or reads your data.

    06Decentralized protocol

    Messages travel through nostr, an open network nobody owns. Anyone can help carry them; no single point can switch it off.

    07Open software platform

    The code is public. Anyone can read it, check it, improve it or start their own version.

    08Global signature hashing

    Everything shared carries a digital signature and fingerprint, so anyone can confirm it is genuine and untouched.

    09One primitive for all data

    Every piece of information uses the same simple building block, which keeps things reliable and easy to move or back up.
