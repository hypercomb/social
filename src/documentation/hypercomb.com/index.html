Chrome / Edge · version 1.2.0

Smart Autolinker

Turns words and phrases you choose into links while writing in rich-text editors.

Install
  1. Download and extract the ZIP.
  2. Open the browser’s Extensions page.
  3. Enable Developer mode and choose “Load unpacked.”
  4. Select the extracted folder.
Permissions

Uses browser storage and requests access to all sites and frames so it can work inside editors you enable. The source is included for inspection.

Chrome / Edge · version 1.0.0

No YouTube Shorts

Removes Shorts surfaces from YouTube and can be switched on or off from its toolbar popup.

Install
  1. Download and extract the ZIP.
  2. Open the browser’s Extensions page.
  3. Enable Developer mode and choose “Load unpacked.”
  4. Select the extracted folder.
Permissions

Runs only on YouTube hosts and uses browser storage to remember whether it is enabled.
